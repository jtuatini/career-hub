Cascade Robotics · Seattle, WA (onsite) · Internship

About the role

Cascade Robotics builds fixed-wing VTOL aircraft for wildfire monitoring. Our Embedded Software Interns write C++17 flight-control and telemetry code that runs on real aircraft, and Python ground tooling for hardware-in-the-loop test rigs. Recent interns shipped a CAN bus fault injector, a barometric altitude fusion fix, and a regression harness that runs on every merge.

Qualifications: pursuing a BS/MS in CS, CE, EE, Aerospace, or similar; strong C++ or Python; comfort with test equipment a plus. $40–$47/hr. Cascade Robotics is an equal opportunity employer.
