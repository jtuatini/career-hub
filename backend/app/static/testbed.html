Software Engineering Intern — Autonomy Platform (Summer 2027)

Meridian Autonomy Labs · Ann Arbor, MI (hybrid) · Internship · Posted this week

About the role

Meridian Autonomy Labs is hiring a Software Engineering Intern (Autonomy Platform) for Summer 2027 in Ann Arbor, MI.

Meridian Autonomy Labs builds perception and controls software for autonomous field robots used in agriculture and infrastructure inspection. Our stack is modern C++20 on the robot (planning, state estimation, sensor drivers) with Python tooling for simulation, data pipelines, and ML evaluation. Interns ship production code: recent interns built a LiDAR ground-segmentation module, cut planner latency 30%, and added CI hardware-in-the-loop tests.

We are looking for interns who have strong C++ fundamentals, comfort with data structures and algorithms, and curiosity about robotics. Experience with ROS 2, Eigen, CUDA, Linux, Docker, or embedded targets is a plus. You will pair with a mentor, own a scoped project end-to-end, and present it at our demo day.

Qualifications: pursuing a BS/MS in CS, CE, EE, Robotics, or similar; graduating December 2027 or later; solid C++ or Python; git fluency. Compensation: $42–$50/hr plus housing stipend. Meridian is an equal opportunity employer.
